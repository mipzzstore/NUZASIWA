# NUZASIWA Website

Website katalog NUZASIWA. Seluruh tampilan, produk, harga, dan tombol WhatsApp berada di satu file: `index.html`.

## Cara memperbarui website dari browser

1. Buka file `index.html` di repository ini.
2. Klik ikon pensil **Edit this file**.
3. Ubah kode yang diperlukan.
4. Klik **Commit changes**.
5. Tunggu beberapa menit sampai GitHub Pages menerbitkan perubahan.

Website: https://mipzzstore.github.io/FOLL/

## Mengaktifkan GitHub Pages pertama kali

Buka **Settings → Pages**. Pada **Build and deployment**, pilih:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Lalu klik **Save**.
